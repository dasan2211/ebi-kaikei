# 国際化（i18n）

UI翻訳は `src/locales/ja.yaml` と `src/locales/en.yaml` で管理する。Reactコンポーネントへ表示文言を直接書かず、`useI18n()` が返す `t()` でYAMLのキーを参照する。

```tsx
const { t } = useI18n();
return <h1>{t("dashboard.title")}</h1>;
```

変数を含む文言はYAML内で `{name}` 形式のプレースホルダーを使う。

```yaml
accounts:
  count: "{count} 科目"
```

```tsx
t("accounts.count", { count: accounts.length });
```

## 言語を追加する場合

1. `src/locales/<locale>.yaml` を追加する。
2. `src/i18n/i18n.ts` の `supportedLocales` とカタログ読込へ追加する。
3. 言語セレクターへ選択肢を追加する。
4. `bun run test` を実行し、全言語の翻訳キー集合が一致することを確認する。

初回起動時は言語選択が完了するまで通常画面へ進まない。選択言語はSQLiteの
`app_settings.initial_setup_locale` と `localStorage` の `ebi-kaikei.locale` に保存され、
その言語に対応する初期勘定科目がRust側の単一トランザクションで登録される。

通常画面で言語を変更すると `localStorage` を更新し、`<html lang>`、ページタイトル、
メタ説明も同期する。勘定科目名は会計データとして扱うため、通常画面の言語切替では
自動改名しない。
