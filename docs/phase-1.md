# Phase 1 最初の縦切り

## ユーザージャーニー

- 個人事業主として、起動直後に今日の作業と主要な帳簿へ移動できる。
- 複式簿記の利用者として、勘定科目コード・名称・区分を一覧で確認できる。
- 入力担当者として、日付・摘要・借方・貸方をキーボードで入力し、貸借差額を即時に確認できる。
- 確定担当者として、Rust側の検証を通過した貸借一致仕訳だけを保存できる。

## 境界

Reactは画面入力と即時フィードバックを担当する。正規の仕訳検証、状態遷移、SQLiteトランザクションはRust側だけが担当する。会計日付は全層で `YYYY-MM-DD` の暦日文字列として扱う。
