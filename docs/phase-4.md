# Phase 4

Phase 4では、通常の仕訳を会計データの中心に保ったまま、消費税、固定資産、棚卸、証憑を追加しています。固定資産と棚卸の処理結果は専用集計だけに保存せず、選択中の帳簿へ貸借一致した確定仕訳を生成します。

## 消費税

- 仕訳明細ごとに税区分を任意指定できます。
- 初期税区分は標準税率10%、軽減税率8%、非課税、不課税、対象外です。
- 税率をコードへ埋め込まず、適用開始日・終了日を持つSQLiteマスターとして管理します。
- 「決算・税務」画面では、選択年度の確定仕訳を税区分別に集計し、税込金額から税抜金額と参考税額を算出します。
- 税集計は申告支援用の参考値です。インボイスの控除割合、簡易課税、免税・課税事業者判定などを含む申告額の確定機能ではありません。

仕訳入力で税区分を選び、「保存して確定」を押すと消費税集計へ反映されます。下書きは集計対象になりません。

## 固定資産と減価償却

「決算・税務」で資産名、資産科目、取得日、取得価額、残存価額、耐用年数を登録できます。現在の償却方法は定額法です。取得年度は取得月から12月までを月割りし、年度ごとに次の確定仕訳を一度だけ作成します。

```text
借方: 減価償却費
貸方: 減価償却累計額（備品）
```

すでに計上済みの年度を再度実行した場合や、償却可能額が残っていない場合は登録されません。

## 棚卸と売上原価

期首商品棚卸高、期末商品棚卸高、棚卸日を入力すると、三分法による次の確定仕訳を一つのトランザクションで作成します。

```text
借方: 仕入 / 貸方: 棚卸資産（期首分）
借方: 棚卸資産 / 貸方: 仕入（期末分）
```

売上原価は、選択年度の確定済み「仕入」勘定の借方純増額として表示します。同じ帳簿・年度の棚卸調整は一度だけ登録できます。

## 証憑・添付ファイル

「証憑」画面で、選択年度の仕訳へPDF、PNG、JPEG、WebPを添付できます。1ファイルの上限は20MBです。

- ファイル形式は拡張子ではなくファイル内容から判定します。
- ファイル名のパストラバーサルを拒否します。
- ファイル本体はBase64やSQLite BLOBとして保持せず、アプリデータ領域の `attachments` ディレクトリへ保存します。
- SQLiteには仕訳との関連、元ファイル名、保存名、メディア種別、サイズだけを保存します。
- バックアップ作成時はSQLiteスナップショットと対応する添付ファイル一式を同時に退避し、復元時も一緒に戻します。
- 外部サービスに保存した証憑は、HTTPSのURLを仕訳へ関連付けることもできます。URL先のファイル本体はEBI Kaikeiのバックアップに含まれません。
- URL保存を税務上の保存として利用する場合は、法定保存期間中の随時閲覧、真実性、検索性などの要件を外部サービス側で満たす必要があります。期限付きURLは失効前にファイルとして保存してください。

## データベース

Phase 4の基本テーブルはスキーマバージョン7で追加され、その後のマイグレーションで貸付金と外部証憑URLに対応しています。`tax_codes`、`fixed_assets`、`fixed_asset_depreciations`、`inventory_counts`、`attachments`、`evidence_links`を使用します。既存データを削除するダウンマイグレーションは自動実行しません。
